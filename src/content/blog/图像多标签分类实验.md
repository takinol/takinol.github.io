```python
class ResizeWithPad:
    def __init__(self, size=224, fill=0):
        self.size = size
        #填充的颜色
        self.fill = fill
        #使用call，使得实例可以像函数一样被调用
    def __call__(self, img):
        w, h = img.size
        # 等比例缩放：让最长边变成 size
        scale = self.size / max(w, h)
        #像素不能有小数
        new_w = round(w * scale)
        new_h = round(h * scale)
        #`torchvision` 的 `Resize` 接收的参数顺序是 `(高, 宽)`
        img = torchvision.transforms.Resize(
            (new_h, new_w),
            #做了平滑过渡——双线性
            #马赛克化
            #interpolation=T.InterpolationMode.NEAREST
            interpolation=torchvision.transforms.InterpolationMode.BILINEAR
        )(img)
        # 计算四周填充量
        pad_left = (self.size - new_w) // 2
        pad_top = (self.size - new_h) // 2
        pad_right = self.size - new_w - pad_left
        pad_bottom = self.size - new_h - pad_top
        img = torchvision.transforms.Pad(
            (pad_left, pad_top, pad_right, pad_bottom),
            fill=self.fill
        )(img)
        return img
        
ResizeWithPad(224,0),
```

经过查阅，当使用预训练模型时，最好的方法是取该模型的某个权重的对应的预处理操作，可以直接应用在测试集和验证集，而对于训练集可以在使用前，加上所需要的强数据增强的手段。*所以不要为了验证正确性而过多的做所谓的为正确性验证做的消融实验。*
但是经下文发现，对于遥感数据可能不太适用中心裁剪，要尽可能的保留上下文，所以可以以社区标准作为baseline 1，再新开一个训练集测试集验证集都用 pad 来处理大小尺寸的 baseline 2 ，注意，这不是做一组消融实验，而是一定要保证训练集和测试集有统一的处理方式，如果交叉时候中心裁剪模型认不出为什么周围有填充的特征

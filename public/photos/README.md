# 照片墙：怎么加照片

## 第 1 步（唯一必做）：把图片复制进这个文件夹

把你拍好的照片直接复制到 `public/photos/` 里就行，构建时会自动扫描。

- **支持格式**：`jpg` / `jpeg` / `png` / `gif` / `webp`
- **不要压缩、不要转格式、不要旋转** —— 原图直接放，网站会自己缩放显示
  （照片墙最大显示 250px 宽，点开放大最大 1200px，浏览器会自动缩小，不会糊）
- **文件名会显示在照片下方**当说明 → 起个好听的名字，比如 `海边日落.jpg`
- **显示顺序按文件名排序** → 想控顺序就用数字前缀：`01-海边.jpg`、`02-猫.jpg`
- **大小档位自动判断**（竖图显示小、横图显示大），不用管
- 删照片 = 把文件删掉，再重新构建

## 第 2 步（可选）：加"便利贴"

点开放大照片时，可以在旁边浮出一张便利贴写故事。编辑 `src/data/photos.ts`：

```ts
export const photoNotes: Record<string, string> = {
  // key = 文件名（不带后缀），value = 想说的话
  '海边日落': '那天风很大，但夕阳特别好看。',
};
```

没写说明的照片，放大时就只显示图片，不出便利贴。

## 第 3 步：构建发布

- 双击仓库根目录的 **`部署网站.bat`**（推荐，不依赖 GitHub Actions）
- 或者 `git add` → `git commit` → `git push`（等 GitHub Actions 自动构建）

## ⚠️ 本地预览的一个坑

`public/photos/` 里**新增或删除文件不会触发 dev server 热更新**，所以本地要看效果必须**重启**：

```
1. 关掉正在跑 npm run dev 的窗口
2. cd D:\A学习\大一暑假\dsh\takinol.github.io
3. npm run dev
4. 打开 http://localhost:4321/photos/
```

用 `部署网站.bat` 则不受影响（它是重新构建）。
